# TravelMaker

TravelMaker 是一套給 Codex 使用的旅行規劃 Skill。使用者用日常語言提供目的地、日期和想去的地方即可開始；Skill 會追問缺少的必要資訊，確認足夠後安排經過動線驗證的行程，並製作可部署的手機優先旅行指揮台。

它不只排行程，也涵蓋：

- 景點間交通時間與轉乘緩衝驗證
- 餐廳研究、訂位窗口與未安排餐期
- 當日行程、提醒、天氣、航班與整合安全警報
- 訂位、交通票券與出發前任務
- 多旅客行李／購物清單與購物參考圖片
- 信用卡、跨境支付與支出紀錄（使用者選擇啟用）
- 一小時智慧更新、保留上次成功快照與手動更新
- 離線旅遊手冊
- 公開 Demo 的去識別化、獨立儲存與發布檢查
- 依旅遊目的地選擇當地官方資訊來源；無可靠來源時標示限制
- 內附原站風格的深色／螢光綠樣式、日期卡片元件與中性範例

## 使用方式

1. 下載此儲存庫。
2. 將整個資料夾放到 Codex 的技能目錄，資料夾名稱保持為 `travelmaker`。
3. 在 Codex 中說明旅行需求，或直接使用 `$travelmaker`。

範例：

> 使用 $travelmaker 幫我規劃 7 天東京旅行。我會提供日期、班機、飯店和想去的地點；如果資訊不足請分批詢問，我不知道的項目可以略過。

Skill 會先整理「已確認／採用假設／暫時略過」，再進行動線驗證、行程與餐廳規劃。信用卡回饋等功能不會預先套用任何人的卡片，只有使用者主動要求時才詢問卡片產品名稱；請勿提供卡號、有效期限、安全碼、銀行帳號或登入資料。

新網站預設沿用 `assets/visual-kit.css` 與 `assets/DaySelector.tsx` 的版型，不會複製參考旅程的姓名、班機、訂位或持卡資料。公開個人行程前需先確認網站可見範圍。
